Insight

Fair market value and replacement value answer different appraisal questions.

The same painting, porcelain, or bronze can require different value conclusions depending on whether the file is for donation, estate, insurance, sale planning, or family division.

Fair market value

FMV is usually used when the appraisal question is market exchange under a defined premise and date. Donation and estate questions often begin here, but the exact standard and documentation context matter.

Replacement value

Insurance work may ask what it would cost to replace an object with a comparable work in the relevant market. For unique or thinly traded Asian art, replacement logic may point to a different number than FMV.

Why the distinction matters

  • A donation file should not quietly borrow an insurance number.
  • An insurance schedule may understate risk if it uses an old FMV file without review.
  • An estate file may need an effective date that differs from today's retail replacement context.

Next step

If the object is being insured, read the insurance art appraisal pathway. If the same object may be donated or inherited, compare it with the FMV appraisal pathway.
