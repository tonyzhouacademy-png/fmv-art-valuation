Anonymized case study

Chinese porcelain donation FMV: from attractive estimate to defensible file.

A donor wanted to support a charitable contribution involving Chinese porcelain. The central problem was not whether the object was beautiful, but which market evidence actually applied.

The question

The donor had an older purchase record, several auction screenshots, and a general object description. The target use was a donation appraisal, so the file needed an FMV conclusion and a documented chain of reasoning.

The evidence gap

The first comparables were too broad. They matched blue-and-white porcelain as a visual family, but did not match form, scale, date language, condition, or sale venue. The strongest appraisal work began by narrowing the object category.

The appraisal approach

  • Rebuilt the object description with measurements, condition, marks, and images.
  • Separated aspirational auction estimates from completed comparable sales.
  • Checked whether condition issues affected this specific collecting market.
  • Linked the donation problem back to official IRS resources and advisor review.

Outcome

The final scope became more precise: not "Chinese porcelain value" but a donation-focused FMV question for a specific porcelain category, condition profile, and effective date.
